PM Dashboard V12 — เมนูเลือกฟอร์ม PM ใน Sidebar

เพิ่มเมนูย่อยแบบ Dropdown สำหรับ 17 กลุ่มฟอร์ม PM ใน Sidebar ทุกแผนก

วิธีใช้:
1. เลือกแผนก เช่น EM2
2. กด Letdown Tanks (หรือกลุ่มอื่น) เพื่อกางรายการ; กดอีกครั้งเพื่อยุบ
3. เลือกรหัสฟอร์ม PM เช่น T5120 จาก Dropdown ใต้กลุ่ม; หน้าเว็บเปิดฟอร์มที่เลือกทันที
4. เปลี่ยนแผนกแล้วเมนูที่กางก่อนหน้าจะยุบอัตโนมัติ
5. ช่องเลือกอุปกรณ์บนแถบด้านบนยังใช้ได้ตามเดิม และซิงค์กับช่องใน Sidebar

ข้อจำกัด/ขอบเขต:
- รายชื่อฟอร์มมาจาก tankGroupMapping ในโค้ดเดิม แสดงทุกอุปกรณ์ในกลุ่ม (ไม่จำกัดเฉพาะที่มีบันทึก)
- ไม่มีการเพิ่ม query ไปยัง Supabase จากการเปิด Dropdown
- ไม่เปลี่ยนฐานข้อมูล, สิทธิ์, ระบบตรวจ PM, Result Note หรือ PDF
- หน้า Sidebar ที่ย่อเหลือไอคอน ให้คลิกชื่อหมวดเพื่อขยาย Sidebar แล้วเลือกได้
- เมื่อเลือกฟอร์มบนมือถือ Sidebar จะปิดเพื่อแสดงฟอร์มที่เลือก
