PM Dashboard V9 — เพิ่ม Result Note (ต่อยอดจาก Administrator + Delete / Glass UI V8 Optimized)
=======================================================================================

การใช้งาน:
1. เข้าระบบตามปกติ แล้วคลิก "Result Note" ใน Sidebar
2. คลิก EM1, EM2, Resin PD1 หรือ WWT ใต้เมนู Result Note เพื่อดูเฉพาะแผนกนั้น
   หรือใช้ตัวเลือก "แผนก" ด้านบนหน้า Result Note
3. รายการแสดงเฉพาะรหัสอุปกรณ์ที่มีข้อความในช่อง Result Note จริง ๆ
   ช่องที่ว่าง/เว้นวรรค และรายการ PM ที่ถูกซ่อนจะไม่ปรากฏ
4. กด "ดูรายละเอียดหมายเหตุ" เพื่อดูข้อความ ชื่อรายการตรวจ และสถานะ OK/NO
5. กด "เปิดฟอร์ม PM" เพื่อกลับไปยังฟอร์มเดิมของอุปกรณ์ที่เลือก
6. กด "อัปเดตข้อมูล" เพื่ออ่านข้อมูลล่าสุดจาก Supabase

สิ่งที่คงเดิม:
- Login, สิทธิ์ Administrator/Admin/View, แสดงอีเมลก่อนออกจากระบบ
- การบันทึกข้อมูล PM, แก้ไข/เพิ่ม/ลบรายการเฉพาะ Administrator
- หน้า Progress, History, Activity Log, Next Due, Admin และ PDF A4
- โหมดโปร่งแสง Light/Dark และการปรับลด Blur เพื่อความลื่นไหลตาม V8

แหล่งข้อมูล:
- อ่านจากตาราง pm_data เดิมโดยใช้ key *_<ลำดับ>_note (ไม่สร้างตารางใหม่)
- ใช้การแยกแผนก/กลุ่มจากรายการอุปกรณ์เดิมในระบบ
- ใช้ข้อมูลล่าสุดที่โหลดจากฐานข้อมูล ไม่ใช่ประวัติย้อนหลังทุกการแก้ไข
- Result Note เป็นหน้าสรุปแบบอ่านอย่างเดียว; ไปแก้ข้อความที่ฟอร์ม PM ต้นฉบับ

ไฟล์ที่เพิ่ม:
- js/result-notes-v9.js
- css/result-notes-v9.css
ไฟล์ที่ปรับ:
- index.html (เมนู หน้าใหม่ และการเรียก CSS/JS)
- js/ui.js (การเปลี่ยนหน้า / สถานะเมนู)
- js/database.js (อัปเดตข้อมูล Result Note หลังโหลดและบันทึก)

การติดตั้ง:
- สำรองเว็บเวอร์ชันเดิมก่อน
- อัปโหลดทั้งโฟลเดอร์ preventive-maintenance-main ทับเวอร์ชัน V8 ที่ใช้
- ตรวจว่ามีทั้ง js/result-notes-v9.js และ css/result-notes-v9.css
- รีเฟรชแบบไม่ใช้แคชด้วย Ctrl + F5
- ไม่ต้องรัน SQL ใหม่สำหรับหน้า Result Note

ผลการทดสอบ:
- ตรวจ JavaScript Syntax ทุกไฟล์ผ่าน
- ทดสอบแสดงฟอร์ม 4 แผนก กรอง แสดงเฉพาะข้อความจริง ซ่อนรายการที่ถูกซ่อน
  ขยายชื่อรายการตรวจ เปิดกลับฟอร์ม และแสดง Dark Glass UI ด้วยข้อมูลจำลองใน Chromium
- ยังไม่ได้เชื่อมทดสอบกับบัญชีและ Supabase จริงของผู้ใช้
