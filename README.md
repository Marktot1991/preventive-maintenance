# Preventive Maintenance Form

โครงสร้างหลังแยกไฟล์ (โหลดตามลำดับใน index.html — ห้ามสลับลำดับ)

- index.html — โครงหน้าเว็บ (HTML)
- config.js — ไฟล์ตั้งค่า Supabase (ต้องเพิ่มเอง ไม่ได้อยู่ในไฟล์ต้นฉบับ)
- css/ — สไตล์แยกตามหัวข้อ
- js/ — โค้ดแยกตามหน้าที่ (state, auth, data, form-render, progress, export-pdf ฯลฯ)
  - js/data/ — รายชื่อถัง/อุปกรณ์/แม่แบบ checklist
