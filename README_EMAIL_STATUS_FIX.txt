PM Dashboard — Administrator + Delete | แก้สถานะแสดงอีเมลผู้ใช้

สิ่งที่แก้:
1. ตำแหน่งเหนือปุ่ม "ออกจากระบบ" แสดง E-Mail ของบัญชีที่เข้าสู่ระบบทุกสิทธิ์
   ไม่ใช้ข้อความ "Online Admin" หรือชื่อบทบาทแทนอีเมล
2. อ่านอีเมลจริงจาก Supabase Auth (getUser) โดยมี fallback จาก session และ profiles.email
3. ปรับตัวหนังสือให้ตัดบรรทัดเมื่ออีเมลยาว (ไม่ถูกตัดด้วย ...)
4. เพิ่มเวอร์ชัน URL สำหรับ auth.js, state.js และ CSS เพื่อเลี่ยงแคชเวอร์ชันเก่า

วิธีติดตั้ง:
- สำรองโค้ดเดิมก่อน
- แตก ZIP แล้วอัปโหลดไฟล์ทั้งโฟลเดอร์ preventive-maintenance-main ขึ้น GitHub Pages
- เปิดเว็บใหม่และกด Ctrl+F5 (บนมือถือให้รีโหลดหน้า/เปิดแท็บใหม่)
- ลองล็อกอินด้วย Administrator, Admin และ View อย่างละบัญชี

หมายเหตุ:
- หากย่อแถบ Sidebar จะเห็นเพียงไอคอนตามดีไซน์เดิม; ขยายแถบจะเห็นอีเมลเต็ม
- ไม่ต้องเปลี่ยนตารางฐานข้อมูลหรือรัน SQL ใหม่
- ไม่ได้ทดสอบกับบัญชี Supabase จริงของคุณ
