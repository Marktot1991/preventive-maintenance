PM Dashboard V15 - Login without outer showcase frame

ปรับหน้า Login เท่านั้น (ต่อยอดจาก V14)
- เอากรอบสีเข้ม/พื้นหลัง/ขอบ/เงาที่ครอบเนื้อหาฝั่งซ้ายออก
- ให้หัวเรื่องและคำอธิบายอยู่บนพื้นหลังโดยตรง
- คงการ์ดข้อมูลย่อย 3 ใบ ภาพตัวอย่าง PM และการ์ด Login ด้านขวา
- ตัวหนังสือในโหมดสว่างเป็นกรมท่า และโหมดมืดเป็นขาวฟ้า
- ปุ่มดวงจันทร์/ดวงอาทิตย์ที่มุมบนเป็นไอคอนชัดเจน
- ไม่เปลี่ยน JavaScript, Login/Supabase, Sidebar, Result Note, PDF

ไฟล์ที่เปลี่ยน:
  index.html (เพิ่มลิงก์ CSS พร้อมเวอร์ชันป้องกันแคช)
  css/login-frameless-v15.css (ไฟล์ใหม่)
