PM Dashboard V10 — Result Note: เลือกดูเฉพาะฟอร์ม (ต่อจาก V9 / Glass UI V8)
==================================================================

สิ่งที่เพิ่ม:
- ช่อง "ฟอร์ม" ถัดจาก "แผนก" บนหน้า Result Note
- "ทุกฟอร์มที่มีบันทึก": แสดงรายการทั้งหมดในแผนกที่เลือก
- "ทั้งกลุ่ม: ...": แสดงเฉพาะกลุ่มอุปกรณ์ เช่น Pigline
- เลือกรหัสฟอร์ม เช่น PGL13, T5120 เพื่อแสดงเฉพาะฟอร์มนั้น
- รายการฟอร์มสร้างจากข้อมูลที่มี Result Note จริง ไม่รวมฟอร์มที่ไม่มีหมายเหตุ
- เมื่อเปลี่ยนแผนก รายการฟอร์มจะเปลี่ยนตาม และรีเซ็ตเฉพาะเมื่อรายการเดิมไม่มีในแผนกใหม่
- การค้นหา, สรุปจำนวนฟอร์ม/หมายเหตุ และปุ่มเปิดฟอร์ม PM ทำงานตามตัวกรองที่เลือก
- เมื่อกดอัปเดตข้อมูล ตัวเลือกฟอร์มจะโหลดใหม่จาก Supabase

วิธีอัปเดต:
1. สำรอง ZIP เวอร์ชันเดิมไว้ก่อน
2. แตก ZIP ใหม่แล้วอัปโหลดไฟล์ทั้งหมดไปแทนชุด V9 ที่ใช้อยู่
3. กด Ctrl+F5 จากนั้นไปที่ Result Note เลือกแผนกและฟอร์ม

ไฟล์ที่แก้: index.html, js/result-notes-v9.js, css/result-notes-v9.css
ไม่ได้เปลี่ยนฐานข้อมูล, ระบบสิทธิ์, การบันทึก PM หรือการพิมพ์ PDF
ผลทดสอบเป็นการทดสอบกับข้อมูลจำลอง ไม่ใช่ Supabase จริง
