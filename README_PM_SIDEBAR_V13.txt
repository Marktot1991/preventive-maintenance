PM Dashboard V13 — แผนกและฟอร์ม PM ใน Sidebar

- ยกเลิกตัวเลือก DEPARTMENT / แผนก ด้านบน Sidebar
- ยกเลิกตัวเลือก เลือกรหัสอุปกรณ์ ด้านบนหน้าเว็บ
- เปิดเมนูแผนก EM1 / EM2 / Resin PD1 / WWT ได้จาก Sidebar (คลิกซ้ำเพื่อยุบ)
- ภายในแผนกมีหมวดฟอร์ม PM เปิด/ยุบได้; กดรหัสฟอร์มเพื่อเปิดข้อมูลการตรวจนั้นได้ทันที
- ฟอร์มที่มีชื่ออธิบายอุปกรณ์ในข้อมูลเดิมจะแสดงชื่อประกอบ ไม่สร้างชื่อเอง
- หน้าฟอร์มแสดงแผนก / กลุ่ม / ชื่ออุปกรณ์ที่เลือกในแถบด้านบนเพื่อบอกตำแหน่ง
- ยังคงเมนู Result Note ตามแผนกและฟอร์มไว้เหมือนเดิม
- ใช้ Supabase การบันทึก PM สิทธิ์ Admin และ PDF เหมือนเดิม
